# Formas

Princípio lido na homepage Creative Tim UI (22 de outubro de 2026). Não é uma receita para copiar.

## O que a origem faz

- Uma família de raio. O filho é menor que o pai para o canto ficar concêntrico.
- Card, miolo de foto, ícone e avatar não inventam um segundo vocabulário.
- Círculo fica para avatar e para o controlo que é um disco.

## O que não entra

`--radius: 0.625rem`, `rounded-xl`, `rounded-3xl`, pill no botão.

## Mapa neste portfolio

- Controlo e campo: `--radius-control` 4px.
- Frame de foto, card, depoimento, chip de logo: `--radius-card` 6px.
- Tag: `--radius-pill` 60px. Só a tag.
- Avatar: círculo. Só o avatar.
- O botão (4px) senta fora do frame da foto (6px). Não há segundo raio dentro da imagem, porque a imagem é o próprio frame.
